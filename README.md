# KurilovDefence

**Название:** KurilovDefence  
**Автор:** Зенков Глеб Геннадьевич
**Группа:** М3112

## Описание

KurilovDefence — простое расширение для Visual Studio Code, предназначенное для тренировки памяти при изучении C++. Оно находит самую длинную распознаваемую функцию в активном исходном файле и открывает отдельный документ, в котором тело этой функции заменено подсказкой. Пользователь должен восстановить код по памяти.

## Возможности

- запуск тренировки из Command Palette;
- чтение текста активного редактора;
- поиск самой длинной функции среди типичных определений C++;
- создание и открытие тренировочной копии исходного файла;
- вывод сообщения, если функция не найдена.
